One line about office life: the printer only ever jams on deadline day, when IT is on holiday.

Reward: $2 · 5 places paid. See the bounty: https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc

## Entry

> The printer has never jammed on a quiet Tuesday — only on deadline day, when IT is on holiday.

## How it works

`main.py` writes the entry above to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` when that variable is unset), with no trailing
newline, exactly as the bounty gate requires.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
